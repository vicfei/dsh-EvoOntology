# dsh-evoontology

**Self-evolving ontology layer for DeepSeek Harness** — an evolution engine with
evidence on every record.

```bash
npm i -g dsh-evoontology
evoontology seed --sqlite mydata.db        # semantic layer from DDL, zero LLM
evoontology evolve start --hypothesis "..."  # budgeted evolution session
```

Zero-infra: `python3` (stdlib only). Full docs:
[github.com/vicfei/dsh-EvoOntology](https://github.com/vicfei/dsh-EvoOntology)
